# Sales Business Performance Dashboard

## Project Overview

This Power BI project analyzes sales business performance using an interactive dashboard and key performance indicators (KPIs).

The dashboard provides insights into sales, profit, orders, quantity, product performance, state-wise sales, monthly sales trends, and payment modes.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Analysis
- Data Visualization

## Key KPIs

- Total Sales: 29.52M
- Total Profit: 6.37M
- Total Orders: 994
- Total Quantity: 2K
- Average Order Value: 29.70K
- Profit Margin: 21.57%

## Dashboard Analysis

The dashboard contains the following visualizations:

1. Monthly Sales Trend
2. Sales by Category
3. Sales by State
4. Profit by Product
5. Sales by Payment Mode

## Business Insights

1. Electronics had the highest sales among all categories.
2. Maharashtra generated the highest sales among all states.
3. Laptop generated the highest profit among all products.
4. Cash on Delivery (COD) generated the highest sales among payment modes.
5. November recorded the highest monthly sales.
6. The overall profit margin was 21.57%.

## Project Objective

The objective of this project is to analyze business sales data, identify important sales and profit trends, and present actionable insights through an interactive Power BI dashboard.
